# 打手目录与评价

## 用户端

- 底部第三个入口由“订单”改为“打手”，原订单列表保留在“我的 → 订单”。客服端和接单员端的订单入口保持原样。
- 打手页沿用现有黑白灰 UI，支持按 Lv 等级筛选、按昵称搜索和分页浏览。
- 仅展示审核通过且未冻结、未删除的打手。等级列表来自当前可展示打手的实际等级，默认等级为 Lv.1。
- 个人主页展示头像、昵称、平台等级、简介、技能信息、服务统计和用户评价，不公开手机号、真实姓名、openid、押金及钱包等字段。
- “写评价”先查询当前用户已完成且未评价的该打手订单，再使用原订单评价流程提交。每个订单限一次，评分范围 1–5 星。
- 评论删除后不恢复订单的“待评价”状态，避免同一订单重复评价。

## 管理后台

- “打手管理 → 编辑”可以设置 Lv.1–Lv.999 和最多1000字的公开简介。
- “打手管理 → 评价”查看指定打手的评价，并在确认后删除。
- 删除采用逻辑删除，保留数据库记录和操作日志；公开列表不再显示，并重新计算打手及商品的平均评分。最后一条评价删除后评分归零。
- 删除权限由后端管理员角色校验，普通用户、接单员、客服均不能调用该接口。

## 接单员端

- “我的 → 个人简介”可编辑本人简介。
- 本人不能修改平台等级，等级由平台管理员设置。

## 增量迁移

迁移文件：`deploy/baota/migrations/20261023-player-directory.sql`。

根目录初始化 SQL 已同步新字段。已有部署需要同时更新后端 JAR、H5 与管理后台静态文件。
