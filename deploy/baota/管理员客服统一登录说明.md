# 管理员与客服统一登录说明

## 登录入口

管理员和客服统一使用管理后台：

`https://jaxapi.kkimg.top`

登录时只需填写用户名和密码。系统会从账号资料中自动识别管理员或客服，不再需要在登录页选择角色。

H5 用户端只保留“手机登录”和“密码登录”，已移除“客服登录”。客服账号请使用上述管理后台地址。

## 已修复的问题

- 后台新增账号时角色可能保存为小写 `admin` 或 `cs`，登录令牌校验原先只识别大写角色，导致密码正确后仍无法登录。
- 登录页原先还需手动选择身份，客服账号误选“管理员”会被拒绝。
- 管理列表中混合大小写角色可能被错误显示成“客服”。
- 编辑账号时可能把旧登录状态字段一并提交。

现在角色在创建和编辑时统一保存为 `ADMIN` 或 `CS`，登录和令牌签发会兼容已有的混合大小写角色。现有账号无需删除或重新创建。

## 账号操作

- 新增管理员：系统管理 → 管理员管理 → 新增管理员 → 角色选择“管理员”或“客服”。
- 修改密码：编辑对应账号，填写8～32位新密码；留空则保持原密码。
- 密码须同时包含字母和数字。
- 连续输错5次会锁定30分钟，可在账号列表中确认状态后再处理。

本次修复不修改数据库结构，不重置任何现有账号密码，不改变已启用或已禁用状态。
