# 打手主页与等级分类

## 管理员

1. 后台左侧「打手等级分类」可新增、改名、排序、停用和删除分类，例如金牌打手、魔王护、高级打手。排序数字越小越靠前。
2. 「打手管理 → 编辑」选择所属等级分类，维护昵称、头像、简介、主页封面、一句语音、相册和故事。
3. 「打手管理 → 评价」沿用管理员删除评价能力。删除后重新计算评分。

默认分类为高级打手、金牌打手、魔王护，可按业务调整。默认分类可以改名、停用；已有打手的分类须先迁出打手后再删除，避免产生失去分类的资料。

停用分类会隐藏该分类及其打手的公开目录与主页，也不能指定这类打手下单。旧数字等级如不在默认分类内，迁移时保留为对应的 Lv 分类，已有记录不会丢失。

## 打手端

「我的 → 我的主页管理」可维护本人的昵称、头像、封面、简介、语音、相册、故事；等级分类由管理员设置，打手本人不能修改。

- 相册最多9张，支持预览、替换、移除。
- 一句语音支持录制；H5还可以上传音频。界面限制60秒、10MB，格式为 mp3、m4a、wav、aac、ogg、webm。上传接口校验文件格式与大小。
- H5录音需要HTTPS、麦克风权限及浏览器支持；不支持录音时可使用音频上传。
- 故事为最多5000字纯文本；简介最多1000字。
- 「保存并预览」在资料保存后打开公开主页；待审核打手需审核通过后才能公开展示。

## 用户端

「打手」首页按后台排序分组，每组展示最多6张卡片；「更多」及上方分类标签进入该分类的完整分页列表。支持昵称搜索。

打手主页有封面、头像、分类、简介、服务数据、语音和「TA的故事 / TA的相册 / 用户评价」标签。

- 私聊：登录用户直接发起与该打手的会话，复用原有聊天与消息入口，无需先下单。
- 点单：选择已有服务商品，再进入原订单确认页，自动选择该打手；提交后仍经过原支付和派单流程。
- 打手离线、满单、被冻结、已删除或所属分类停用时，不能指定TA下单；后端也会校验，避免仅依赖界面限制。
- 评价继续要求用户完成该打手订单，每单限一次；管理员可以删除。
