## 已修复

- 删除 H5 通用固定验证码，新增图形验证码、一次性短信验证码、服务端 HMAC 摘要存储、五分钟有效期、单次消费、尝试次数和多层频率限制。短信未配置或未验收时登录失败关闭。
- 用户换绑手机号必须同时验证原号码和新号码；数据库增加非空手机号唯一索引，阻断并发重复绑定。
- 订单详情和进度增加归属校验；普通 USER 不能再访问 PLAYER 接口；打手端订单列表移除账号、联系人等敏感字段。
- 收款账户新增、修改、删除和提现均校验当前打手归属；提现保存收款账户快照，后续改账户不会改变历史申请。
- 聊天身份完全来自服务端令牌，禁止 `chatRole` 或消息体覆盖身份；会话创建、读取、发送、已读和短信提醒统一校验成员关系。
- WebSocket 改为连接后的首帧认证，JWT 不再进入 URL、Nginx 日志或浏览器日志；握手限速，未认证连接 30 秒关闭，每条消息重新检查会话和账号有效性。
- 商品写操作和维护开关仅管理员可用；接口文档不再公开；路径规则仅对明确 GET 开放。
- 通用上传改为登录后可用，仅接受 JPG、PNG、GIF 和受支持音频；限制大小和频率，对图片解码后重新编码为 PNG，阻断 SVG、脚本和伪造扩展名。
- 支付证书移出公开上传目录，证书上传仅接受对应 PEM 内容，并设置目录和文件私有权限。公开文件映射只匹配随机文件名的允许扩展名。
- 微信支付回调在 SDK 验签和解密后，继续核对 AppID、商户号、币种、精确到分的金额、支付单号、业务类型、订单归属和状态，并保证支付交易号唯一。错误通知返回失败 HTTP 状态。
- 微信退款改为本地持久化退款任务后异步提交和查单，只有 `SUCCESS` 才标记退款完成；增加 30 秒支付查单和退款恢复任务。
- 余额支付、充值入账、提现申请、审核、退款和结算统一到数据库事务和行锁；通过故障注入验证流水失败时余额、订单、支付单和提现记录全部回滚。
- 停用账号、修改密码、修改角色和换绑手机号后，旧 HTTP/WebSocket 会话自动失效；登录上下文与 JWT 中的用户 ID、角色必须一致。
- 管理员实体不再输出密码哈希；系统配置密钥在后台显示为掩码；异常响应不再返回 SQL、类路径和驱动错误。
- CORS 仅允许 `https://jax.kkimg.top` 和 `https://jaxapi.kkimg.top`；Spring Security 在鉴权前处理 OPTIONS 预检。
- 补充 HSTS、CSP、nosniff、X-Frame-Options、Referrer-Policy 和 Permissions-Policy；管理端与 H5 的 8081/8082 只绑定 `127.0.0.1`，由本机反向代理访问。
- 实现缺失的管理端公告推送接口，按用户和打手批量推送、重复调用幂等。
- 管理端富文本使用 DOMPurify 白名单清洗；管理端生产 npm 审计为 0。

主要代码变更位于 `delta-game/delta-common`、`delta-user`、`delta-player`、`delta-order`、`delta-pay`、`delta-cs`、`delta-admin` 和 `delta-admin-ui`。数据库增量迁移为 [2026-10-23-security-fix.sql](./2026-10-23-security-fix.sql)。
