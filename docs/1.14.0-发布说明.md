# Delta 1.14.0 发布说明

- 发布日期：2026-11-12
- 适用组件：后端、管理后台、H5；小程序本批不新增功能包
- 数据库：schemaVersion=1

## 用户与运营变化

- 新增主题商店和柔光拟态主题；主题必须由授权中心设置正式价格并上架，客户后台才能购买和启用。
- 协同打单支持队伍容量内并行邀请，要求满员后才能开始；队友接受前确认邀请时的分成方案，退款按累计比例精确冲正。
- 网页登录增加主登录方式、手机验证码、密码辅助和公众号登录开关，并在服务端强制执行；公众号首次登录可完成邀请归因和手机号补全。
- 新增授权中心按次计费二要素实名接入；未配置服务商时明确拒绝，不扣费、不伪造认证成功。
- 新增用户会员等级、会员折扣快照、优惠券中心、首单邀请奖励、退款冲正待追回台账、消费排行和最近购买动态。
- 消费排行允许用户退出；最近购买默认不公开，只有用户主动同意后才展示脱敏昵称和商品名。
- 后台新增营销活动中的优惠券管理和邀请奖励页面，订单详情展示会员与优惠券优惠快照；授权中心新增实名用量账户。
- 新增功能默认关闭，既有客户的登录、购买、订单、支付、退款、结算和通知行为保持不变。

## 缺陷修复

- 修复 statistics_daily 字段名与每日统计任务不一致的问题。任务原先写 new_orders/completed_orders/new_users/new_players/total_complaints，但三客户实际表结构使用 new_order_count/completed_order_count/new_user_count/new_player_count/new_complaint_count，导致每日 01:00 报 Unknown column 'new_orders'。
- 每日统计现在同时计算新增/活跃用户、新增/完成/取消订单、净成交额、平台收益、打手收益、新增/活跃打手、新增投诉和平均客单价。
- 启动兼容逻辑为旧环境补齐 statistics_daily 缺失列；没有删除或改写历史数据。
- 新增 SQL 回归测试，直接读取定时任务 Mapper SQL，在测试库执行并校验统计结果。

## 发布前必须配置

- 主题：在授权中心设置正式价格并上架；未上架时客户端只显示草稿/不可购买状态。
- 公众号 OAuth：客户需要自己的 AppID、AppSecret，并在微信公众平台配置网页授权域名。
- 微信支付：继续使用各客户自己的商户号、证书和回调配置，授权中心不保存客户支付私钥。
- 二要素实名：配置授权中心服务商 URL、Token、摘要密钥、单次价格，并为对应实例充值服务余额。

## 回退

更新执行器在安装前备份数据库、上传文件和环境配置。若健康检查失败，执行器应回退到上一发布目录；本版本只做可重复执行的加列/建表兼容，不删除字段，不回写业务数据。
