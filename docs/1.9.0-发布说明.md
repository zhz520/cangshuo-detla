# 1.9.0 公众号通知四角色独立模板

- 系统配置中的公众号通知改为四份角色模板组：客户、打手、管理员、客服。
- 每份模板组支持 `new_order`、`order_accepted`、`order_completed`、`material_reviewed`、`withdraw_reviewed` 五个事件，可分别填写不同的模板 ID 和字段映射。
- 订单支付、打手接单和订单完成会向相关客户发送通知，同时按 `order.read` 权限通知管理员和在线客服；打手继续接收指派、素材审核和提现审核通知。
- 角色模板为空时自动回退到旧版通用模板，不影响已有公众号配置。
- 客户、打手、管理员和客服必须使用各自身份登录 H5 后绑定公众号 OpenID。

## 配置位置

在「系统管理 → 系统配置 → 公众号通知」中分别维护：

- 客户专属模板组：`wechat.official.templates.user`
- 打手专属模板组：`wechat.official.templates.player`
- 管理员专属模板组：`wechat.official.templates.admin`
- 客服专属模板组：`wechat.official.templates.cs`

## 安装方式

客户自行进入「功能与更新 → 系统更新」安装 1.9.0。后端、管理后台和 H5 必须同批更新。
