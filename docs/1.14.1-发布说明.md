# Delta 1.14.1 发布说明

- 发布日期：2026-11-12
- 适用组件：后端、管理后台、H5；本批无小程序功能变更
- 数据库：schemaVersion=1，无结构变更

## 修复

- 修复主题启用接口 `/admin/platform/themes/active` 调用付费授权检查时未传递当前请求域名的问题。
- 服务端原先把空域名当作“不在授权域名列表”，因此已购买、已启用且后台域名登记正确的主题仍返回“当前访问域名未获得此模块授权，请使用购买时登记的域名”。
- 修复后主题启用会传入当前后台域名，按现有 license 的 `allowedDomains` 校验；错误域名仍会被拒绝，合规域名可以正常启用。
- 该修复对当前 747 的柔光拟态主题和未来购买主题的租户同时生效；不会改变订单、价格、权限、域名归属或主题授权数据。
