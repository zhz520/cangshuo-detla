# 1.8.2 客服与管理员公众号绑定入口

- 补齐客服与管理员 H5 登录页，解决原快捷入口指向未注册页面而无法进入客服工作台的问题。
- 管理员和客服登录后，在客服工作台“我的”页面可以看到“公众号消息通知”。
- 在微信内置浏览器打开 H5、登录对应后台账号后，可进入“公众号消息通知”完成绑定或解绑。
- 用户、打手、客服和管理员分别保存公众号绑定关系；同一公众号 OpenID 不能重复绑定同一身份的多个账号。
- 后端、管理后台和 H5 作为同一批必要更新发布，组件版本统一为 1.8.2。

## 安装方式

客户自行登录所属项目管理后台，进入「功能与更新 → 系统更新」，检查并安装 1.8.2。升级后管理员和客服在微信内打开 `https://jgs.kk520yy.com/#/pages-cs/login/index`，使用各自后台账号登录，再从“我的 → 公众号消息通知”完成绑定。
