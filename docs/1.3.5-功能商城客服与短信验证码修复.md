# 1.3.5 功能商城、客服入口与短信验证码修复

## 公众号模板通知

公众号通知作为独立付费模块进入功能商城，授权中心默认价格为 100 元。没有对应签名授权时不能启用；即使系统配置里打开了公众号开关，绑定接口和后台发送任务也不会执行。授权中心的功能与定价页面支持新增、查询、编辑和删除模块；已有订单或授权的模块禁止删除，可改为草稿停用。

## 客服接入

后台“系统配置 → 客服配置”可选择系统内置客服，或填写第三方企业微信客服 HTTPS 链接。H5 首页悬浮客服、底部客服入口和商品详情客服会使用同一配置。第三方链接模式可直接跳转，不要求用户登录。

## 短信与验证码

保留以下短信能力：

- H5 手机号验证码登录与密码重置。
- 用户、打手和客服聊天短信提醒。
- 打手被指派、队友邀请业务短信。
- 手机号、IP、全局频控、冷却与打手扣费。
- 短信模板、签名、AccessKey、Endpoint 与 OTP 开关配置。

登录页获取短信成功后不再刷新图形验证码；只有发送失败、图形验证码错误或用户主动刷新时才更新图形验证码。

本次发布后端、管理后台和 H5 1.3.5。
