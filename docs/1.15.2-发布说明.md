# Delta 1.15.2 发布说明

- 发布日期：2026-11-14
- 基线版本：1.15.1
- 数据库 schemaVersion：1（无结构变更）

## 修复

打手处于休息中（is_online=0）时点击接单，后端返回“打手未通过审核或账号已冻结”，实际账号是 ACTIVE 且已通过审核；前端在接单失败后又强制把弹窗切成验证码输入，造成“验证码关不掉”的错觉。

现在接单挑战接口和接单接口都会先判断在线状态，休息中返回“当前处于休息中，请先开启接单状态后再接单”；前端接单失败不再把验证码模式强行打开，休息中会提示先开启接单状态并提供去开启入口。

管理后台打手等级验证由裸开关改为“免验证/需要图形验证码”明确选项；保存时如果未修改验证设置，不再提交该字段，避免旧页面把手动关闭的验证码重新写回开启。已根据后台最近修改记录恢复被误覆盖的等级验证设置。
