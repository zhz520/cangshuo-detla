# Delta 1.14.6 发布说明

- 发布日期：2026-11-12
- 适用组件：后端、管理后台、H5；小程序版本号同步，本批无小程序业务变更
- 数据库：schemaVersion=1，无结构变更

## 管理端补齐

- 订单详情新增协同打手列表、组队人数、邀请/接受/拒绝状态、分成方案和邀请/接受时间，组队单不再只能到打手端排查。
- 新增结构化会员等级管理，可启停会员权益、增删等级并设置累计净消费门槛和折扣率；等级越高折扣不能变差，最低等级门槛必须为 0 元。
- 优惠券页新增最近领取与核销记录；已有用户领取后，禁止修改优惠券类型、面额和使用门槛，避免改变已发券价值。名称、状态、总量和后续领取限制仍可调整。
- 邀请奖励页支持把待追回欠款标记为已追回；操作幂等、并发安全，只关闭台账，不自动改动用户余额。
- 新增敏感词管理，支持分类筛选、关键词搜索、启停、编辑和删除；启用的敏感词用于主页资料审核。
- 新增内容页面管理，可维护用户协议、隐私政策和其他富文本页面；内容键创建后不可修改，防止客户端协议链接失效。

## 修复

- 修复用户 H5 协议页读取 `content` 字段，而后端实际返回 `configValue`，导致已配置协议仍显示空白的问题。
- 修复邀请欠款“先查询再更新”的并发窗口，改为条件更新并按实际结果判断。
- 统一会员默认规则来源，后台、用户会员页和下单计价不再各自维护不同默认值。
- 管理端订单详情、会员、优惠券、邀请、敏感词和内容页面完成 PC 与 320/390/430 宽度 H5 验收。

## 验证

- 后端 395 项、管理后台 78 项、H5 96 项、更新执行器 50 项、迁移工具 21 项、QA 工具 2 项测试通过，0 failures / 0 errors。
- 管理后台生产构建和 H5 构建通过；管理后台与 H5 静态资源引用缺失均为 0。
- 本地真实浏览器 39/39 场景通过，覆盖 PC 和 320/390/430 宽度、营销页面、协同订单详情、敏感词保存、富文本内容编辑、弹窗宽度和横向溢出。

## 升级说明

- 本次不新增数据库表或字段，更新执行器仍使用 `schemaVersion=1`。
- 后台新入口位于“营销活动”和“平台设置 → 内容与活动 / 系统管理”。
- JAX、742、747 继续通过 `delta-shared-prod` 服务组签名计划统一升级；客户后台不提供共享后端独立安装按钮。
