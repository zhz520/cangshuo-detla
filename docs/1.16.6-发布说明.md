# Delta 1.16.6 发布说明

- 升级基线：生产共享组 1.15.5；业务改动来自 520 已验证的 1.16.5 源码。
- 目标：`delta-shared-prod` 的 JAX、742、747，使用服务组签名计划。
- 520 演示站数据库、演示图片、部署配置、域名和授权状态不随包发布。

## 用户可见变更

- 更新商城、打手目录、个人中心、消息及后台的界面。分类可使用内置图标，轮播标题、副标题和按钮文案由后台设置。
- 增加客服分组、按商品与分类分流、会话结束及评分。未配置分流时，旧订单和新订单仍进入公共池。
- 用户协议与隐私政策继续读取本租户后台正文。未配置时展示 1.15.5 完整正文，并使用本租户站名。关于我们由后台独立配置。
- 历史图片 URL 和原图仍保留；更新不重新写入客户图片或配置。

## 升级与恢复

- 后端启动兼容检查新增客服路由表、订单客服归属、会话评分、轮播文案和图标尺寸；不导入演示数据。
- 会话唯一索引改用按状态生成的列。新索引建立后才删除旧索引，允许保留多个已关闭会话；回退为 1.15.5 程序后，旧版 SQL 仍由新索引限制每对用户至多一条活动会话。
- 共享执行器备份三租户后统一切换三个组件。失败优先回退程序与发布指针，保留兼容字段；需要恢复业务数据库时先核对备份至恢复期间产生的写入。
- 上线前后分别核对公网域名、业务 API、静态资源、财务基线、授权和版本。

## 发布前验证

- 后端 412 项测试，后台 84 项测试，H5 108 项测试，更新器 50 项测试通过。
- 三个组件构建通过，后台和 H5 静态引用无缺失。
- 隔离 MySQL 8.4.4 中对 1.15.5 和 1.16.5 两种会话索引执行两次迁移。确认数据保留、活动会话唯一、旧版 SQL 可关闭后重新发起，且不涉及支付数据。
