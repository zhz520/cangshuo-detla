# 1.11.0 后台 PC/H5 入口拆分

本次版本把管理后台的 PC 和 H5 入口明确分开，并移除按窗口宽度自动跳转的逻辑。

## 入口变化

- 后台 PC 固定使用根路径 `/`，登录页为 `/login`。
- 后台 H5 固定使用 `/h5/`，登录页为 `/h5/login`，工作台为 `/h5/dashboard`。
- 手机用户需要自行打开后台域名的 `/h5/`，后台不再自动根据窗口宽度切换。
- PC 登录页增加“手机端入口”，H5 登录页增加“电脑版”返回入口。
- PC 页面继续保留移动端布局、表格卡片适配和安全区处理，误在手机上打开时仍可操作。

## 兼容

- `/mobile` 和 `/mobile/...` SPA 路由已移除；旧 H5 和书签暂时由一个静态兼容脚本跳转到 `/h5`，待三套客户 H5 更新后删除脚本。
- 后台读取旧公众号配置或发起授权时，会把 `/mobile/wechat-binding` 自动改写为 `/h5/wechat-binding`，避免旧配置导致绑定失败。
- 客户 H5 的 `staff-entry` 默认入口改为 `/h5/login` 和 `/h5/dashboard`；旧 `/mobile` 链接由静态脚本分流。

## 更新安全

- 继续使用一个 admin 构建产物，不新增更新组件。
- admin ZIP 仍保留根 `index.html` 和 `cangshuo-version.json`，更新执行器的组件名、健康检查和挂载路径不变。
- 不依赖宿主 Nginx 新增 `/h5/` 配置；`/h5/...` 深链由同一个 SPA 的根 `index.html` 承接。
- 不依赖宿主 Nginx 新增路径；`/mobile` 已不再注册为页面。
