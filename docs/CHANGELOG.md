# 版本与发布记录

## 1.23.4 · H5 懒加载与底栏稳定性

- 构建前清理旧产物，H5 代码块使用 ASCII 文件名，避免中文文件名在 Linux 解压后变成乱码导致 404；生产改用 Python zipfile 保留 UTF-8 文件条目。
- 底部页签增加启动占位条和跨页共享滚动锁；占位脚本作为同源外部文件加载，兼容站点 CSP，不阻塞点击。路由懒加载失败时最多自动刷新一次。

## 1.23.2 · H5 底部页签过渡修复

首次进入分类等底部页签时保留旧画面，避免 UniApp 替换页面造成白屏重载；新页随后淡入，页签栏保持稳定。支持 View Transition 的浏览器使用旧屏快照，旧 WebView 退回页面上浮。四个底部路由仅在空闲时预取代码，不预取业务数据。

## 1.23.1 · 导航动效修正

后台和客户 H5 区分前进、返回和同级切换，支持减少动态效果。保留 1.23.0 的展示偏好功能。从 1.22.3 直升时，备份后独立执行 `20261124-wechat-display-preference.sql`；不回填偏好，应用回退保留新表。

## 1.23.0 · 公众号卡片优先展示偏好

支持按公众号和模板继承或覆盖优先展示字段，不修改微信模板或关键词，不代表微信客户端已生效。升级前须备份并独立应用 `20261124-wechat-display-preference.sql`；不回填数据。回退应用时保留新表。

统一管理端和 H5 页面切换、减少动态与错误重试；修复商品读取失败及押金退款页空态图片。保留既有通知、支付和租户配置行为。

## 1.21.0 · 扫码后自动配置公众号模板

- 管理员扫码授权后，后台任务按角色和通知场景核对该公众号的微信模板库，匹配签名方案、字段和关键词顺序。不能安全匹配的场景保留人工处理入口，不覆盖已配置或停用的映射。
- 未找到模板时，仅在有模板库编号和关键词的情况下申请添加；重新同步并验证后才绑定。重试不盲目重复添加。
- 业务通知可以独立选择发件公众号，不改变登录和支付默认号。配置过程不向真实用户发送消息。
- 公众号菜单支持可视化编辑和预览校验；粉丝资料按批同步。
