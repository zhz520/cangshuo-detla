# 1.3.1 后台菜单补丁

本次发布管理后台组件，后端和 H5 继续使用已有版本。客户在系统更新中选择“后台菜单分组与权限过滤”；需要的 1.3.0 后端由现有必要更新规则自动加入。

菜单整理为六组，保留原有 36 个页面入口及地址：

| 分组 | 菜单 |
| --- | --- |
| 工作台 | 仪表盘、客服服务（在线回复、快捷回复、聊天记录） |
| 业务运营 | 订单与售后（订单、投诉、换人、接力）、商品管理 |
| 人员管理 | 用户与隐私、打手与审核（打手、等级、邀请、素材、上下班） |
| 财务结算 | 收益日报、分账台账、提现、打赏、收益分析、充值套餐 |
| 平台设置 | 内容与活动（轮播、公告、打赏与抢单）、系统管理（配置、管理员、角色、公众号通知、日志） |
| 功能更新 | 功能商城、系统更新 |

按基础身份和每个子页面的权限过滤菜单，没有可用入口的分组自动隐藏。未来新增且尚未安排分组的页面暂列“其他功能”，避免遗漏入口。

默认展开当前页面所属菜单，其他菜单自动收起。新增/编辑商品、聊天详情仍高亮所属列表；桌面支持图标折叠与浮层子菜单，手机抽屉内部滚动并在选择页面后关闭。

验证：3 项权限与导航逻辑测试；PC、iOS WebKit、安卓 Chromium、320px 小屏及受限客服账号回归，逐项核对 36 个入口没有遗漏或重复。浏览器模拟不替代真机验收。
