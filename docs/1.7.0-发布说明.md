# 1.7.0 后台批量操作

- 商品列表新增批量上架、下架、调整分类、统一设置价格、按比例调价、复制为下架草稿和删除。
- 商品批量修改使用整体事务；选中商品中有记录失效、分类停用、编号为空、重复或超过单次上限时，会整体拒绝并提示刷新后重试。
- 用户列表新增批量恢复正常、封禁和删除。余额、冻结金额、未完成支付、订单和关联打手等原有业务保护继续生效，成功和失败项分别统计。
- 打手列表新增批量审核通过、驳回、调整等级和解冻。驳回只处理待审核申请，解冻只处理已冻结打手，停用等级不能批量分配。
- 三处批量操作均提供勾选栏、二次确认和逐项结果提示；查询、翻页或操作完成后自动清空选择。
- 本版同步后端、管理后台和 H5 版本号。H5 业务代码与本版其他组件保持同一发布批次。

## 安装方式

请登录所属项目的管理后台，进入「功能与更新 → 系统更新」，点击「检查正式版」，查看发布说明后安装 1.7.0。后端、管理后台和 H5 作为同一批必要更新安装。微信小程序由项目方按既有流程另行提交，版本号为 1.7.0（165）。
