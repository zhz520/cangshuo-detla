# Delta 1.14.3 发布说明

- 发布日期：2026-11-12
- 适用组件：后端、管理后台、H5；本批无小程序功能变更
- 数据库：schemaVersion=1，无结构变更

## 客户 H5 调整

- 消费排行、会员等级、优惠券和邀请好友从首页移到“我的”页面。
- 首页只保留商品、公告、分类和按授权条件展示的最近购买悬浮滚动条，避免运营入口继续挤压商品。
- “我的”页面把四项集中放入“会员与权益”2×2 区域，并保留最近购买/排行的标签直达。
- “我的”页面重新分组为：账号资料、订单钱包快捷区、会员与权益、接单员入口、账号与安全、帮助与协议。
- 接单员入口按实际状态展示：未入驻、审核中、工作台、冻结或重新申请。

## 隐私与行为

- 消费排行和最近购买仍遵守展示开关与用户授权设置。
- 会员、优惠券和邀请入口在未登录时引导登录，不展示其他用户数据。

## 验证

- H5 Node 测试和生产构建通过；后台与 H5 静态引用检查通过。
- 后端全量 380 项、管理后台 74 项测试通过。
- 添加首页入口移除、“我的”权益分组、账号安全/帮助协议分区和接单员状态回归测试。
