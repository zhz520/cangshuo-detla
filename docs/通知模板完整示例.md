# 公众号与业务短信配置指南

通知配置页已经改为直接填写，不再要求用户手工编写 JSON。按角色选择事件后，只需要填写模板 ID、模板变量和系统数据源；页面会自动生成并保存后台使用的配置。

本指南依据微信官方文档核对，核对日期为 2026-11-08：

- [模板消息说明](https://developers.weixin.qq.com/doc/service/guide/product/template_message/Template_Message_Interface.html)：最后编辑于 2026-03-05。
- [发送模板消息接口](https://developers.weixin.qq.com/doc/service/api/notify/template/api_sendtemplatemessage)：最后编辑于 2025-11-25，变更日志更新于 2025-11-26。

当前接入的是服务号“模板消息”，不是小程序订阅消息，也不是服务号订阅通知。官方说明仍允许模板消息正常使用，同时订阅通知处于灰度阶段。

## 一、微信公众号后台怎么开通

1. 使用已经完成微信认证的服务号登录公众平台。普通订阅号、未认证服务号不能调用模板消息接口。
2. 在“功能 → 添加功能插件 → 模板消息”申请模板消息权限。
3. 按服务号所属行业设置服务类目。每个服务号最多设置 5 个类目，每月可修改 5 次。
4. 进入公共模板库或“我的模板”，选好模板并添加到账号。每个服务号最多同时使用 25 个模板。
5. 打开“我的模板 → 模板详情”，复制模板 ID。一个事件对应一个模板 ID。
6. 官方默认日调用上限为 10 万次；粉丝量提升后的额度以公众平台“开发者中心”显示为准。

模板正文中的变量必须保留 `{{ }}`，变量名必须以 `.DATA` 结尾。后台填写字段名时只填变量名前缀，例如正文 `{{thing1.DATA}}` 对应字段名 `thing1`。

## 二、当前支持的模板字段

官方发送接口的 `data` 结构如下，系统会自动生成这部分内容：

```json
{
  "thing1": { "value": "新订单" },
  "character_string2": { "value": "DG202611080001" }
}
```

当前文档列出的模板字段类型和系统限制如下：

| 字段类型 | 用途 | 当前限制 |
|---|---|---|
| `thing` | 事物、名称、短说明 | 最多 20 个字符 |
| `character_string` | 编号、订单号、字符串 | 最多 32 个字符 |
| `time` | 日期或时间 | 支持日期、时间及时间段，系统最多保留 64 个字符 |
| `amount` | 金额 | 1 个币种符号加最多 10 位数字，可带小数 |
| `phone_number` | 电话号码 | 最多 17 个字符 |
| `car_number` | 车牌号码 | 最多 8 个字符 |
| `const` | 平台审核过的固定枚举值 | 最多 20 个字符，只能发送审核通过的枚举 |

旧版 `phrase` 字段已不在当前官方发送接口文档的字段列表中。新配置请使用 `thing`、`character_string`、`time` 等当前类型。

公众号模板没有任意长文本变量。`thing` 最多 20 个字符，因此不要把整段长通知正文塞到单个 `thing` 字段中。系统数据源 `message` 仍可用于短信或兼容旧模板，但公众号建议使用以下结构化字段。

## 三、页面里每个字段怎么填

| 页面字段 | 填写内容 |
|---|---|
| 微信模板 ID | 公众号“我的模板”详情中的模板 ID |
| 消息点击链接 | 选填。必须是 `http://` 或 `https://` 地址，后端通过官方发送接口的 `url` 参数提交 |
| 小程序 AppID | 选填。必须和页面路径同时填写；同时配置时微信优先跳小程序 |
| 页面路径 | 选填，例如 `pages/order/detail?id=123` |
| 模板变量 | 正文中的变量名前缀，例如 `thing1`、`character_string2`、`time6` |
| 系统数据 | 当前变量要显示的业务数据，见下一节 |

防重复消息 ID 由系统自动生成，采用当前通知队列 ID，不需要人工填写。官方说明同一 `openid + client_msg_id` 在 10 分钟内只发送一条。

## 五、推荐的公众号模板正文

订单类事件可以使用以下模板。不要继续使用 `phrase`。

```text
{{thing1.DATA}}
订单号：{{character_string2.DATA}}
金额：{{amount3.DATA}}
客户：{{thing4.DATA}}
打手：{{thing5.DATA}}
时间：{{time6.DATA}}
```

推荐字段为：`thing1=status`、`character_string2=orderNo`、`amount3=amount`、`thing4=customerName`、`thing5=playerName`、`time6=time`。如果需要不同的文案，可以在微信公众号后台选用与这些字段类型一致的模板。

人员审核类事件可以使用：

```text
{{thing1.DATA}}
审核时间：{{time2.DATA}}
```

推荐字段为：`thing1=status`、`time2=time`。

## 六、官方发送接口包含哪些参数

官方接口地址为：

```text
POST https://api.weixin.qq.com/cgi-bin/message/template/send?access_token=ACCESS_TOKEN
```

| 参数 | 是否必填 | 系统处理 |
|---|---|---|
| `touser` | 是 | 使用绑定记录中的公众号 OpenID |
| `template_id` | 是 | 使用页面填写的微信模板 ID |
| `data` | 是 | 按页面中的模板变量与系统数据自动生成 |
| `url` | 否 | 使用页面填写的消息点击链接 |
| `miniprogram` | 否 | 使用页面填写的小程序 AppID 和页面路径 |
| `client_msg_id` | 否 | 系统按通知队列 ID 自动生成，防止 10 分钟内重复发送 |

官方错误码中最常见的是 `40037`（模板 ID 无效）、`47003`（参数格式或字段内容不符合模板要求）和 `40003`（OpenID 不属于当前公众号或用户状态异常）。

## 七、阿里云短信后台怎么配置

1. 登录阿里云控制台，进入“短信服务 → 国内消息 → 模板管理 → 添加模板”，选择通知类模板。
2. 模板正文使用 `${变量名}`，例如：

```text
${message}订单号${orderNo}，客户${customer}，打手${player}，状态${status}，金额${amount}元，时间${time}。
```

3. 提交审核，审核通过后复制模板 Code，通常在 `SMS_` 开头。
4. 在配置页直接填写模板 Code，并按行添加参数：左侧填 `${}` 中的变量名，右侧选择系统数据源。
5. 在“短信签名”和系统“短信配置”中维护审核通过的签名、AccessKey ID 和 AccessKey Secret。
6. 短信模板不能发送未审核文案，变量数量、变量名和顺序都必须与审核模板一致。
