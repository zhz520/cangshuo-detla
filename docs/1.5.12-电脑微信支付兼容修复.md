# 1.5.12 电脑微信支付兼容修复

- 电脑微信内置浏览器与手机微信同样包含 `MicroMessenger` UA，原逻辑会把电脑微信误判为手机微信并打开公众号 JSAPI 支付页。
- 电脑微信通常不能可靠调用 `WeixinJSBridge.getBrandWCPayRequest` 收银台，因此电脑微信改为展示公众号授权支付二维码。
- 用户使用手机微信扫码后，在手机微信内完成 OAuth 和 JSAPI 支付；电脑普通浏览器原有二维码路径保持不变。
- 手机微信内仍直接使用公众号支付；微信外手机浏览器仍按现有 H5 规则处理。
- 微信外手机浏览器同时启用 H5 和公众号支付时，优先使用更适合移动浏览器的 H5；仅在 H5 未启用时回退到公众号授权二维码。

## 多端路由检查

| 运行环境 | 期望处理 |
| --- | --- |
| 微信小程序 | 小程序 `uni.requestPayment` |
| iOS、Android、HarmonyOS 微信内 | 公众号 OAuth + JSAPI |
| Windows、Mac 电脑微信内置浏览器 | 展示公众号授权二维码，由手机微信扫码 |
| 普通电脑浏览器 | 展示公众号授权二维码 |
| 微信外手机浏览器，H5 已启用 | H5 微信支付 |
| 微信外手机浏览器，仅公众号支付 | 展示二维码并提示使用微信扫码或识别 |
| iPad 桌面模式 | 按触摸能力识别为移动设备，微信内使用公众号支付 |
| 未启用可用支付方式 | 不发起空跳转，显示未启用提示 |

验收：电脑普通浏览器和电脑微信内置浏览器均展示二维码；手机微信扫码后能够进入 OAuth 回调并拉起收银台。
