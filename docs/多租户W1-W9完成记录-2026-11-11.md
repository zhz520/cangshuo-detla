## 1. 完成范围

### W1 租户登记、开通与控制面导出

- 授权中心实例增加显式 `runtimeTenantId`，使用数据库约束和部分唯一索引防止重复；不再把实例 UUID 当运行租户编号。
- 新增已认证 `GET /api/runtime/tenants`，导出 `tenantId`、实例 UUID、客户/项目、域名、维护期、启用状态和服务组编号，不返回密码、私钥、支付密钥或 Token。
- 新增服务组、成员和发布计划数据模型，实例只能属于一个共享服务组。
- 新增 `deploy/updater/tenant_onboarding.py`：默认 dry-run，合并授权导出和 root-only 凭据文件，校验实例 UUID、域名、租户和凭据一致性，原子写入 0600 注册文件并支持脱敏审计。
- 新增 `scripts/bootstrap-runtime-tenants.mjs`：显式映射三个实例和运行租户，写入服务组，按事务提交并写审计。
- 2026-11-11 生产授权库已迁移并完成映射：

  - 服务组：`delta-shared-prod`

### W9 共享服务组签名发布与执行器

- 授权中心新增服务组发布页面和 API：选择已发布正式版本、当前版本、维护窗口，生成 `cangshuo-shared-release-v1` Ed25519 签名计划。
- 计划绑定服务组、启用租户集合、`schemaVersion=1`、三个制品 URL/大小/SHA-256、维护窗口和失效时间。
- 新增 `shared_worker.py daemon`：只轮询私有 inbox，计划先原子 claim，再验签、备份、下载、解包、版本检查、Compose 切换、健康检查、审计和清理；失败进入 rejected。
- 新增 Docker 执行器镜像、systemd 模板和安装器；生产主机使用 Python 3.11 容器，不依赖 CentOS 7 的 Python 3.6。
- 生产已安装 `cangshuo-shared-worker.service`，当前保持 disabled；配置 `allow_execute=false`，状态目录 0700，Docker socket 只读挂载，容器 `cap-drop ALL`。
- 使用 `v1.12.4` 制品生成生产预验计划，服务组、三客户租户集合、窗口、签名和三个摘要全部通过 `shared_worker validate`；在 `allow_execute=false` 时按设计阻止安装。

## 4. 数据与安全边界

- 未读取或输出密码、私钥、支付密钥、JWT、数据库凭据或完整手机号。
- 生产授权库更新前有 root-only 源文件、runtime 和 Compose 备份。
- 共享计划执行器不接受客户端命令、任意路径、容器名或数据库迁移。
- 客户业务数据库仍按租户独立，未跨客户复制业务数据。
