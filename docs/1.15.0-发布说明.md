# Delta 1.15.0 发布说明

- 发布日期：2026-11-13
- 基线版本：1.14.13（生产） / 1.14.14（主题分支）
- 数据库 schemaVersion：1（无结构变更）

## 主题

拟态主题覆盖客户 H5、打手 H5 与管理后台 PC/H5。客户侧首页增加品牌引导，分类页改为两列分类卡，我的页面按服务分组，打手页增加品牌头图，商品卡使用横向封面；订单、钱包、消息、会员、优惠券、邀请、收益、提现、入驻与协议页面统一雾蓝画布、浮起卡片、内凹输入框和蓝色线性图标。管理端 PC、手机浏览器访问的 PC 页面和独立 /h5 后台同步浅色侧栏与拟态组件。

主题必须购买授权后启用，默认主题保持原样；所有拟态样式仅在 neumorphism 主题下生效。

## 修复

打手入驻审核通过时，审批逻辑把 player.reject_reason 更新为 NULL，生产库该字段为 NOT NULL，导致接口 500。现在单个通过与批量通过都写入空字符串，并在与生产一致的非空约束下增加回归测试。

## 验证

- 管理端 83 项测试通过，生产构建通过。
- 客户 H5 101 项测试通过，H5 构建通过。

- 后端审批回归测试 2 项通过。
