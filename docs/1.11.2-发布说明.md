# 1.11.2 PC 与 H5 手机体验区分、头像与跨端修复

本次版本把 PC 手机视图和 H5 明确分成两套体验，统一工作人员头像、加载与页面动画，并完成 iOS、Android、微信和 QQ WebView 的全页面回归。

## 入口区分

- PC 在 1024px 以下改为紧凑电脑版：顶部菜单按钮打开完整侧栏抽屉，保留 PC 仪表盘、运营分析和桌面信息密度。
- PC 不再显示移动底部导航；账号菜单提供手机版入口、待办中心、系统通知和客服消息。
- H5 继续使用独立移动外壳、移动工作台、顶部返回和五项底部导航。
- PC 在手机上不再自动跳转 `/h5`，两个入口的行为和视觉现在都能明确区分。

## 工作人员头像

- 后台顶部、H5 工作台、账号面板和公众号绑定页统一使用 `StaffAvatar`。
- 已上传个人头像优先显示，并使用缩略图；未上传时显示站点品牌 Logo；品牌 Logo 未配置时显示品牌名称首字。
- 图片加载失败自动回退到品牌首字，不显示破图。
- 侧栏品牌 Logo 同样优先使用站点 Logo，未配置时回退品牌首字。

## 加载、动画与跨端

- 统一页面切换动画为 150ms 淡入与轻微位移，减少页面跳动。
- 统一 Element Plus 加载遮罩、全局顶部加载条和错误/重试反馈。
- 安装客户端平台识别，写入 `data-client`、`data-os` 和移动标记，便于按微信、QQ、iOS、Android 做样式和后续兼容。
- 微信和 QQ WebView 关闭毛玻璃背景，降低滚动掉帧。
- 统一安全区、100dvh、触控反馈、输入框 16px、横向表格滚动、禁止悬停粘连和减少动画偏好。
- PC 手机菜单抽屉和 H5 底部导航都避免安全区遮挡，键盘打开时 H5 隐藏底栏。

## 安全与业务修复

- H5 登录过期和系统维护跳转保持在 `/h5`，不再跳到 PC 登录页或 PC 更新页，并保留原页面回跳。
- 功能商城支付跳转增加 HTTPS 校验，本地开发仅允许 localhost 的 HTTP 地址。
- 富文本继续使用 DOMPurify、标签/属性白名单和 URI 白名单，不使用未经净化的 `v-html`。
- 检查外部新窗口链接均带 `noopener noreferrer`，未发现 `eval`、`new Function`、私钥或明文密钥进入前端。
- 管理后台和授权中心生产依赖 `npm audit` 均为 0 vulnerabilities。
- 所有敏感路由继续经过角色、员工权限和付费功能守卫；删除、退款、提现、冻结、批量处理保留二次确认和后端校验。
