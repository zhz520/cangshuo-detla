# 1.8.0 资金安全与收藏复购

- 订单收益改为“待结算收益”和“可提现余额”两段式管理。售后观察期结束后，系统在无进行中投诉、退款时自动释放收益。
- 退款会优先冲正待结算收益，避免先提现后追回；结算失败进入可重试任务，并记录失败原因。
- 订单结算统一由一个入口处理，使用订单抽成快照，修复重复监听和硬编码抽成口径风险。
- 打手提现新增收款人与实名认证或入驻真实姓名一致性校验，不匹配时禁止提现并提示修改账户。
- 商品详情新增收藏，打手主页新增关注；我的页面新增「收藏与关注」统一入口。
- 已完成、已取消和已退款订单新增「再次下单」，自动带出原商品、动态下单信息、常用信息和指定打手；商品下架或原打手不可接单时会提示重新选择。

## 安装方式

客户自行登录所属项目管理后台，进入「功能与更新 → 系统更新」，检查并安装 1.8.0。后端、管理后台和 H5 作为同一批必要更新安装。系统启动会以可重复执行的方式增加资金和会员运营所需表结构及配置项。
