# 1.11.2 页面、业务与安全检查

检查日期：2026-11-09

## 页面范围

管理后台 PC 和 H5 共用业务页面，但使用不同外壳：

- PC：`/dashboard`、订单、用户、打手、商品、退款、投诉、履约、提现、聊天、统计、平台与系统管理，共 47 个路由页面。
- H5：同一批业务页面的 `/h5` 深链，共 47 个路由页面，另含 H5 登录页。
- 异常页：PC 和 H5 的 403、404 均保留各自外壳。

## 页面验收结果

- H5 47 个页面在 320、390、440、768 四个视口完成 188 次加载和 1316 项布局断言，无缺壳、空标题、横向溢出和卡片宽度异常。
- PC 47 个页面在 320、375、768、1024 四个宽度完成 192 项检查，确认菜单抽屉、桌面仪表盘、无移动底栏和手机版入口。
- iOS Safari、Android Chrome、微信 iOS、QQ Android 四套 UA 下覆盖全部 PC/H5 页面，共 376 次页面加载，0 失败。
- 头像专项：上传头像优先、品牌 Logo 回退、品牌名称首字回退全部通过。
- H5 返回链路：工作台、列表、商品编辑取消、聊天记录详情、403/404 深链返回均通过。

## 业务逻辑检查

- 路由权限继续由 `meta.roles`、`meta.permission` 和 `meta.feature` 三层控制；高风险页面没有移除后端权限校验。
- 删除、退款、提现、冻结、批量上下架、批量删除和审核操作保留二次确认；退款仍需客服初审与管理员终审。
- PC 手机视图移除底部导航后，待办、系统通知、客服消息和手机版入口都保留在账号菜单。
- H5 登录过期和系统维护跳转保持在 `/h5`，并携带原页面回跳地址。
- 工作人员头像统一使用 `StaffAvatar`，不再各页面各用一套回退逻辑。

## 安全检查

- 富文本编辑器使用 DOMPurify、允许标签/属性白名单、样式白名单和 URI 白名单，未发现未经净化的 `v-html`。
- 未发现 `eval`、`new Function`、`document.write` 等动态执行入口。
- 外部新窗口链接均使用 `noopener noreferrer`；微信授权回调继续限制为 `https://open.weixin.qq.com/`。
- 功能商城支付地址增加 HTTPS 校验，本地开发只允许 localhost 的 HTTP 地址。
- 登录回跳继续拒绝协议相对地址和外部地址。
- 未发现私钥、API v3 密钥、支付证书或客户密码进入前端源码。
- 管理后台和授权中心生产依赖使用 npm 官方审计源检查，均为 0 vulnerabilities。
- 移动端审计报告的 25 项来自 uni-app 构建工具链（Babel、esbuild、jimp 和 CLI 内部 i18n）；构建后的 H5 产物中没有 `intlify`/`vue-i18n` 运行时代码，本轮不强行跨版本升级构建工具，避免破坏 uni-app 编译链，后续跟随官方工具链升级。
- 后端权限、订单归属、支付回调、退款并发和游客边界继续由既有 273 项后端测试覆盖。

## 已知边界

- UA 模拟不能完全替代真实 iOS、Android、微信和 QQ 设备；正式安装后仍需在客户设备完成一次登录、列表、聊天、弹窗和键盘输入抽查。
- 管理 Token 仍按现有 Bearer + 浏览器存储架构使用，本轮未改登录协议；XSS 防护依赖前端净化和后端权限校验。
- 后端测试主要使用 H2，生产 MySQL 的锁、索引和方言仍需以既有生产迁移与回归记录为准。
