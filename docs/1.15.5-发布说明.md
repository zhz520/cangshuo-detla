# Delta 1.15.5 发布说明

- 发布日期：2026-11-14
- 基线版本：1.15.4
- 数据库 schemaVersion：1（无结构变更）

## 修复

- 客服临时冻结真正写入解冻时间，并新增客服解冻接口和按钮调用；客服不再误用管理员接口。
- 禁止删除当前登录管理员或最后一个启用中的管理员。
- 退款申请处于待审、初审、终审、处理中或失败状态时，暂停订单自动确认、结算和待结算收益释放，避免退款未完成先结算。
- 暂未开放的部分退款由接口和后台表单同时拦截，避免把部分退款记成整单退款。
- 关闭“新支付”不再停止历史 PAYING/REFUNDING 的支付对账和退款恢复。
- 共享租户 Redis 支付超时键使用租户前缀，超时监听改为从任意前缀中解析订单号。
- H5 工作台“待审核”快捷项可打开待办中心；客服不再看到仅管理员可用的提现入口。
- 结算台账使用本地日期，清空日期范围后清空旧数据。
- 后台订单指派/结单、投诉退款/冻结按钮按权限显示；部分退款选项禁用。
- 下单下拉字段必须有选项；打手昵称不能为空；聊天发送失败保留输入；订单详情与进度拆开加载；接力通过和未知投递重发增加确认。

## 验证

- 后端 403 项测试全部通过（0 failures / 0 errors）。
- 管理端 83 项、客户 H5 101 项测试通过，三端构建通过。
- 默认和拟态主题下客户 H5 56 条路由、管理端 PC/H5 各 54 条叶路由全部到达并截图；发现项均为合成 fixture 缺口或无法自动确认的空列表。
- 数据库结构不变，不需要迁移。
