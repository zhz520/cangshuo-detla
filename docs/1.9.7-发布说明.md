# 1.9.7 通知数据源扩展与部分更新修复

- 公众号与业务短信的系统数据源扩展为 78 项，配置页按通知、客户、订单、打手、退款、投诉、提现和接收人分组展示。
- 新增客户联系电话、订单金额、商品名称、商品规格、派单时间、抢单/接单时间、打手电话、退款状态、投诉仲裁、提现账户等常用字段。
- 配置下拉框支持按中文名称或字段编码搜索，并显示示例值和数据说明；完整字段表已写入《公众号与业务短信配置指南》。
- 公众号和短信共享同一业务数据解析服务：订单关联客户与打手，退款和投诉加载该订单最新业务单，提现按提现 ID 读取金额和收款快照。
- 提现事件不再误查同号码订单；公众号金额类型字段自动补币种符号，短信保留纯数值。
- 后台允许配置的系统数据源与前端目录使用同一套键名校验，并增加前后端字段集合一致性测试。
- 修复部分组件更新时活动 H5 发布目录被历史清理误删的问题。更新器现在保留正在挂载的整个发布目录及其嵌套组件，避免页面变成目录索引 403。

本次不需要数据库迁移。安装 `1.9.7` 时后端与管理后台应同批更新；包含客户端的项目可一并更新 H5。

## 安装方式

客户自行登录所属项目管理后台，进入「功能与更新 → 系统更新」安装 `1.9.7`。公众号通知配置页需要后端与管理后台同批更新后才能显示新增字段。
