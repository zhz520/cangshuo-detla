# 沧烁 Delta 1.12.2 补丁发布说明

- 版本：`1.12.2`
- 版本类型：PATCH，参数错误状态修复与静态资源发布门禁
- 数据库：`schemaVersion=1`，无结构变更

## 修复内容

- 管理接口缺少必填请求参数时返回 HTTP 400 和 `code=400`，不再落入通用异常返回 500。
- 保持 1.12.1 的缺失静态资源 404、WebSocket 跨租户 Origin 403 和限流 429。
- 新增 `deploy/qa/check_static_assets.py`，打包和 CI 检查后台/H5 所有静态引用；支持校验 ZIP 与实际解压目录一致。
- Nginx 模板对 `/assets/`、`/static/` 缺失文件返回 404，入口 HTML 和实例配置禁缓存。

## 版本对齐

- 后端 catalog、管理后台、H5 和小程序统一为 `1.12.2`。
- 小程序 `versionCode=185`。

## 验证要求

- 后端全量测试、管理后台和 H5 测试、生产构建通过。
- 静态资源检查通过，JAX、742、747 当前静态目录只读审计无缺失引用。
- 客户 H5 登录态、订单、钱包、消息、资料、实名和打手入驻页面通过浏览器验收。
