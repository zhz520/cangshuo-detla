2026-11-02。基于正式版 1.2.0，保留客户品牌、运营数据、已配置的等级、支付及提现流程。

## 后台入口

- 系统管理 → 角色与权限：新增角色、配置退款权限、分配员工。退款操作还需要能够查看相应订单。
- 入驻邀请、主页素材审核、上下班管理、隐私与注销申请：独立业务入口。
- 自动分账台账：按日期查询与导出 Excel。客服提成比例是**俱乐部抽成中的占比**，下单时保存；未关联处理客服的订单不计该项。记录台账不会直接发起银行分账。
- 系统管理 → 公众号通知记录；系统配置 → 公众号通知、内容风控、入驻配置、结算配置。
- H5 登录 → 密码登录 → 忘记密码；用户“我的”提供隐私与账号注销入口；各身份“我的”提供公众号绑定入口。

## 外部配置与验收边界

### 短信重置密码

使用现有短信验证码通道和已有图形验证码、发送限流、过期及一次性校验。验证码用途 `RESET` 与登录、换绑分离。重置密码后提升账号会话版本，原用户和关联打手会话失效。

需要客户已有短信服务开关、签名、验证码模板和有效凭据。未启用时明确提示服务未开放；不能绕过验证直接重置。

### 公众号模板通知

需要具备相应权限的公众号 AppID、AppSecret、网页授权域名及模板编号，接收人需关注公众号并完成对应身份绑定。公众号 openid 与小程序 openid 分开保存，同一微信可分别绑定用户和打手身份。

在系统配置中设置 `wechat.official.*`。回调地址填 H5 的 HTTPS 首页地址，不含查询参数或 `#`。系统会把回调的 `code/state` 转交绑定页面，绑定状态与登录身份、有效时间和一次性凭据关联。

每个节点的模板映射示例（字段名必须替换为账号实际模板的字段）：

```json
{"templateId":"实际模板ID","fields":{"thing1":"message","character_string2":"orderNo","time3":"time","amount4":"amount"}}
```

字段值可选 `message/status/time/orderNo/amount`。五类节点分别为新订单、接单、完结、素材审核、提现审核。值班客服及管理员接收新订单处理通知。发送失败最多重试五次，超过一天的积压通知过期；发送日志只保留安全错误码。

当前未提供该公众号及真实模板材料，真实微信送达仍需配置后验收，不能用接口测试替代真实发送验收。

### 图片与语音检测

内置文本敏感规则直接生效。图片和音频内容识别需要可用检测服务，通过 `risk.media.endpoint`（HTTPS）与 `risk.media.token` 配置。协议为带 Bearer 令牌的 POST：

```json
{"text":"待检测文本","profile":{"avatar":"图片地址","albumImages":[],"voiceUrl":"语音地址","story":"个人故事"}}
```

检测端须完成图片内容识别/OCR和音频转写审核，返回 `{"verdict":"SAFE"}` 或 `{"verdict":"BLOCK"}`。本版本提供检测网关适配，并未内置图片语义模型或音频转写模型。无配置、超时或结果不明确时资料进入待系统检测，人工不能越过系统检测批准。入驻头像批准同样校验检测结果。

真实图片/语音识别仍需要配置检测供应商后验收。只有系统拦截或人工明确勾选为违规的资料计入冻结阈值；普通编辑驳回不计违规。

### 设备限制

设备绑定依据当前浏览器保存的随机标识，服务端保存其 SHA-256 摘要并结合已验证手机号约束。清理存储、更换浏览器或设备会改变标识；网页无法可靠保证识别同一台物理设备，疑似马甲仍需人工审核。

## 资金与维护逻辑

退款确认后按原订单各打手实际分成比例冲正，逐分分配保持总额一致，重复事件不重复扣款。余额不足时留存待追回款，不静默丢弃差额；后续结算优先追回，并限制有待追回款的提现。台账保留原始分账与独立退款冲正，不改写原始订单金额。

原有用户在规定状态下取消未履约订单的自动原路退款规则保留；后台人工退款及售后仲裁中的退款按角色权限校验。

项目到期仍暂停业务，但保留登录、密码恢复、维护更新、支付结果回调及隐私申请入口，避免无法登录续期或处理注销。入驻、下单等业务不会因此开放。

## 发布与更新

`schemaVersion` 保持 1；本次仅在启动时以 `CREATE TABLE IF NOT EXISTS` 创建新增业务表，不清理客户表或覆盖已保存配置。更新前由现有执行器备份，保留品牌目录、运行配置及登录存储命名；健康检查失败回退原组件。新建表会保留，不在回退时删库。

客户端更新目录提供后端治理与权限、后台操作入口、H5 注册与密码恢复三个组件。后台及 H5 更新项依赖本次后端，仍由客户在系统更新页面选择。生产业务不得使用测试邀请码或测试支付数据验收。
