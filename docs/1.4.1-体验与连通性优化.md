# 1.4.1 体验与连通性优化

本次正式版保留现有品牌、业务数据和功能配置，统一优化打手端、管理后台及授权运营中心，并修复部分更新、提现和并发业务中的连通问题。

打手端重新整理工作台的信息层级，增加收益概览、接单状态和工作入口；统一加载骨架、失败提示、重试和空状态。大厅分类、订单筛选、收益、提现、邀请、审核记录等页面避免重复提交、分页跳页和旧请求覆盖新页面。后台不可见时暂停提醒轮询与背景动效，并尊重系统的减少动态效果设置。

管理后台和授权运营中心统一页面切换、局部加载和错误反馈；客户、模块、订单、版本等高密度表格改为前端分页，保留各页搜索和翻页状态。后台不可用的付费功能不会提前请求对应接口，功能入口按授权和权限分别控制。

版本检查改为按后端、管理后台、H5 的实际组件版本判断。整体版本相同但某个组件落后时仍会显示对应更新，回退后也不会仅依赖历史安装记录误报已安装。

H5 聊天连接改为跟随当前客户域名，避免共享前端包连到其他实例。押金补交增加 H5 微信支付，支付金额仍由服务端按当前等级和已到账押金计算；客户端只接收支付编号和 H5 地址，到账以原有微信验签回调为准。累计补缴达到当前等级要求后可继续提交入驻或提现。

业务修复包括：下班、冻结或未通过审核的打手接单时统一校验；客服派单、队友接受邀请与自主抢单共用活跃订单上限和行锁；组队参与订单进入打手今日完成及待处理统计；撤单、退款和并发提现继续使用原有权限和资金规则。

验证覆盖 50 项移动端单元/接口状态测试、管理后台与授权中心的 Node 回归、后端 Maven 测试、7 组打手端浏览器场景（iPhone、Android、微信、QQ、320px、桌面和减少动态效果）、8 组授权中心跨端场景及 10 项授权中心失败/会话专项。H5 和微信小程序均完成生产构建。
