# 1.9.3 手机运营后台查重与高频操作收尾

- 手机端管理员、客服工作台继续采用简洁卡片布局，待指派、服务中、待审核、退款和投诉在首屏集中展示。
- 今日访客、登录日活、有效订单、收款以及在线/离线打手前置；点击在线人数可直接查看具体打手。
- 待指派订单直接进入可派单列表，派单页默认只展示在线打手，并支持切换全部打手。
- 订单列表和详情显示完整客户手机号，支持一键拨号；详情底部操作栏固定，指派返回后自动刷新。
- 手机端管理入口完成查重：待办和审核中心已覆盖的目的地不会再出现在业务快捷入口中。
- 原“订单管理”改为语义明确的“待确认订单”，只打开待确认状态；提现、人员、商品、公告、员工、咨询等入口按实际能力归类。
- 修复手机端导航查重测试，覆盖工作台、我的页面和统一待办页，防止后续更新重新引入重复模块。

## 安装方式

客户自行登录所属项目管理后台，进入「功能与更新 → 系统更新」，检查并安装 `1.9.3`。后端、管理后台和 H5 属于同一发布批次，建议同批更新；客户业务数据不会被覆盖。
