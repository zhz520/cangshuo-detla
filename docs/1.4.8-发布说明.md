# 1.4.8 微信支付验签诊断与支付入口统一

- 前端所有支付入口统一显示“微信支付”，不再向用户展示公众号支付、H5 支付或小程序支付等技术名称。
- 微信支付应答验签失败时单独返回“微信支付配置校验失败”，后台日志明确提示从当前商户号重新下载成对的微信支付公钥与公钥 ID。
- 驻场押金、提现补押金、余额充值和订单支付继续统一遵循手机后台的支付方式开关。
- 微信内置浏览器使用公众号支付，微信外手机浏览器使用 H5 支付；电脑端或不可用场景不再跳转微信 OAuth 白页，而是提示复制链接到微信或手机浏览器完成支付。
- 后台微信支付配置说明补充公钥下载路径和错误原因，避免把其他商户号、商户证书或旧公钥上传到当前项目。
