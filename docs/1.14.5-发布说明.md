# Delta 1.14.5 发布说明

- 发布日期：2026-11-12
- 适用组件：后端、管理后台、H5；本批无小程序功能变更
- 数据库：schemaVersion=1，无结构变更

## 修复

- 未登录直接打开用户 H5 订单列表或订单详情时，先同步会话并跳转登录，不再先请求接口后抛未处理异常。
- 订单列表增加加载失败提示和点击重试；订单详情增加鉴权、参数校验和可重试错误页。
- 游客会话仍可查看自己的订单；正常登录用户的订单流程不变。
