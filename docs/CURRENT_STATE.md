- 后端要求 Java 17；本机默认 Java 25 不可直接用于正式构建。
- 生产共享后端保留 `JAVA_TOOL_OPTIONS=-Djava.net.preferIPv4Stack=true`。
- H5 的微信支付回调页保留专用 CSP location，不能为了修复调起而放宽全站 CSP。
