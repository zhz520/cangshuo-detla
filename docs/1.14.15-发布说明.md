# Delta 1.14.15 发布说明

- 发布日期：2026-11-13
- 基线版本：1.14.13
- 数据库 schemaVersion：1（无结构变更）

## 修复

管理后台打手入驻审核点击「通过」时，接口返回业务 code 500，页面提示“服务暂时不可用，请稍后重试”。

原因：审批通过时把 player.reject_reason 更新为 NULL，生产库该字段为 NOT NULL，触发数据库完整性约束异常。

修复：审批通过统一写入空字符串，单个审核与批量审核共用同一逻辑。历史驳回原因会在通过后清空，不再阻塞状态流转。

## 验证

- PlayerDirectoryIntegrationTest 使用与生产一致的非空约束，单个通过、批量通过共 2 项测试通过。
- 数据库结构不变，不需要执行迁移。
