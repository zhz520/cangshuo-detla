# Delta 1.18.0 发布说明（候选）

- 版本：1.18.0
- 基线：共享组 1.17.0
- 分支：`codex/shared-1.18.0-arch`
- 构建提交：以 `release-manifest.json` 为准
- 状态：候选构建，未打标签、未上传 GitHub Release、未生成共享组计划、未部署

## 用户可见变化

- 管理端统一页面标题、表单分组、数据表格和异步状态组件
- 打手管理压缩表格列，操作改为「详情 + 更多」，修复固定列遮挡押金和状态
- 打手等级、结算台账、角色权限、通知记录统一使用新设计组件
- 后台消息提示和确认框统一去重、停留时间和交互
- 修复 OpenAPI 文档与 Spring Framework 6.2 不兼容导致的 500

## 技术与护栏

- springdoc 2.8.17，移除 Knife4j starter
- OpenAPI schema 标记管理员密码和短信密钥 writeOnly
- 后端新增 OpenAPI 基线测试、提现并发审核测试
- 管理端新增 API 边界测试和设计系统静态测试
- ArchUnit 3 条冻结规则：Controller 不依赖 Mapper、common 不反向依赖业务、业务模块不依赖 admin
- endpoint / OpenAPI / TypeScript 三类契约基线
