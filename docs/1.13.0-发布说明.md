# 1.13.0 发布说明

- 发布日期：2026-11-11
- 正式版本：`1.13.0`
- 数据库 schema：`1`
- 适用组件：后端、管理后台、H5、微信小程序

## 用户可见变化

- 修复已完成微信退款收到延迟重复通知时的幂等处理。退款单号、原支付金额和退款金额一致时，历史交易号缺失不再导致回调持续返回失败。
- 微信支付恢复任务对超过 24 小时仍未支付的支付单增加受控关单：先向微信查询，只有确认 `NOTPAY` 或已关闭时才将本地 `PAYING` 关闭；`SUCCESS` 仍走原有幂等入账，`USERPAYING/ACCEPT` 继续等待。
- 管理后台、H5 和客户业务接口保持现有入口与权限不变。

## 运维与共享服务组能力

- 授权中心新增显式运行租户导出、共享服务组成员管理、发布计划签发和计划审计。
- 新增租户凭据合并工具，支持默认 dry-run、原子写入、0600 权限、脱敏审计和建库 SQL 模板。
- 共享执行器新增私有 inbox 守护模式；计划必须先验签，执行前备份数据库和文件，组件按后端、后台、H5 顺序健康检查，失败回退，回退失败保持维护门禁。
- 新增受限 Docker 运行镜像和 systemd 安装模板，避免依赖宿主机 Python 3.6 的旧 cryptography 环境。

## 验证

- 后端全量测试：执行 `mvn -pl delta-admin -am verify`，结果记录在构建日志。
- 管理后台：`npm test`、`npm run build`。
- H5 与小程序：`npm test`、`npm run build:h5`、`npm run build:mp-weixin`。
- 更新器：`python -m unittest discover -s deploy/updater -p "test_*.py"`。
- 迁移工具：`python -m unittest discover -s deploy/migration -p "test_*.py"`。
- 静态资源：`python deploy/qa/check_static_assets.py` 检查后台和 H5。
- 授权中心 `0.7.0`：Node 单元测试、Vite 生产构建、运行时租户导出与服务组签名计划集成验证。

## 数据库与回退

- 本版本不新增业务表或字段，`schemaVersion` 保持 `1`。
- 共享服务组升级前必须备份各租户 MySQL、上传文件、租户授权状态和 Compose 配置。
- 执行器健康检查失败时恢复原 Compose 覆盖和组件版本；回退失败保留维护门禁，禁止继续发布。
- 本次共享组生产发布使用授权中心签名计划，不从客户副本重新构建，不跨客户复制数据。
