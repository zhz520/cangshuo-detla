# Delta 1.18.1 发布说明

- 版本：1.18.1
- 基线：共享组 1.18.0
- 分支：`codex/release-1.18.1`
- 数据库：`schemaVersion=1`，启动时增量补齐 `player.deposit_override_amount`

## 用户可见变化

- 恢复打手“单独押金应缴”：后台打手详情可按人设置押金金额。
- 填写 `0` 表示该打手免押金；留空或点“恢复统一”时沿用全局或等级押金规则。
- 已缴押金仍按实际支付累计显示；客服只读，管理员可修改。
- 打手押金支付、提现前补缴和押金退款统一使用该有效应缴金额。
- 单独押金区域使用现有默认、暗黑和拟态主题变量。

## 技术与安全

- 新增管理员专用接口 `PUT /admin/player/{id}/deposit-amount`，由 `/admin/**` 管理员权限保护并写操作日志。
- 金额限制为 0 至 1,000,000 元，保存时统一两位小数。
- 新增启动兼容检查和两份可重复执行的加法迁移。
- 退款通知校验失败继续记录脱敏上下文，不改变资金结果。
