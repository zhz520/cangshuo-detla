## 3. 切换步骤

1. 变更单审批，记录版本、commit、release manifest、维护窗口和负责人。
2. 停写前做最终 MySQL、上传、私密、平台配置和 `.env` 备份，校验 SHA-256。
3. 停止 JAX 写入，排空任务和聊天，确认支付保持关闭。
4. 导入目标库，核对表数、关键行数、钱包/订单/交易/退款/提现/结算。
5. 文件同步：`file_delta.py compare/sync/verify`，确认 missing/changed 为 0。
6. 财务对账：`financial_reconciliation.py audit --fail-on-violation`。
7. 把 JAX 租户注册到生产共享注册文件，验证两个数据源和 `delta:jax:` 缓存键。
8. 切换 `jaxapi.kkimg.top` / `jax.kkimg.top` 到共享后端，验证站点、后台/H5、API、文件和 WebSocket。
9. 客户完成登录、下单、派单、聊天、退款、提现、上传和 H5 返回键验收。
10. 观察期结束后停止旧 JAX 独立容器，保留备份；不能删除旧数据库。

## 4. 回滚

- 先把域名/Nginx upstream 切回旧 JAX 独立后端，验证旧站点和 API。
- 恢复旧 JAR、旧后台/H5 和旧 Compose 覆盖；健康检查失败时保留维护门禁。
- 目标库写入无法安全合并时，停止共享后端写入并恢复最终备份；恢复后逐笔核对 JAX 订单、退款和账户余额。
- 支付保持关闭，避免回滚期间产生支付差异。
- 状态机记录 `rolled_back`，保留旧库、上传、配置和备份。
