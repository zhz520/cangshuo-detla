# 1.6.1 功能商城授权同步修复

- 功能商城的「刷新」改为「同步授权」，直接读取授权中心的最新授权和价格，并显示上次成功同步时间。
- 同步失败会保留上次成功读取的授权、价格和时间，不会把原数据清空。
- 从授权中心支付页返回原浏览器中的功能商城时，自动同步一次；同步标记只消费一次，避免重复请求。
- 后端同步请求改为短时间合并：页面操作和后台定时任务同时触发时不会重复访问授权中心。
- 本补丁同时对齐后端、管理后台和 H5 的版本号。H5 功能代码与此版无差异，客户端后台应按同一批必要更新安装三个组件。

请登录所属项目管理后台，进入「功能与更新 → 系统更新」，检查正式版并安装 1.6.1。无需修改授权中心服务或微信支付商户配置。
