# 1.9.6 公众号模板直接填写与官方字段更新

- 公众号模板配置由整段 JSON 编辑改为按角色、事件直接填写。
- 每个事件可填写微信模板 ID、消息点击链接、小程序跳转、模板变量和系统数据源。
- 页面自动生成并保存底层配置，用户无需手工编写 JSON。
- 按微信官方当前模板消息字段更新示例和校验：`thing`、`character_string`、`time`、`amount`、`phone_number`、`car_number`、`const`。
- 移除旧版 `phrase` 推荐字段，并在页面说明各字段长度和格式限制。
- 公众号发送接口支持可选 `url` 和 `miniprogram`，并自动生成 `client_msg_id` 防止重复发送。
- 配置页提供官方模板消息说明、发送模板消息接口链接、最后编辑日期、四角色五事件最终通知示例和常见错误说明。
- 官方依据：模板消息说明页最后编辑于 2026-03-05，发送模板消息接口页最后编辑于 2025-11-25；本次按 2026-11-08 拉取内容核对。

## 安装方式

客户自行登录所属项目管理后台，进入「功能与更新 → 系统更新」安装 `1.9.6`。后端和管理后台需要同批更新。
