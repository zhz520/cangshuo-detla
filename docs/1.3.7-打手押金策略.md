# 1.3.7 打手押金策略

后台“打手配置”新增押金政策：

- 必须交押金：保持原有入驻押金金额和支付流程。
- 全部不需要押金：入驻和提现均不校验押金。
- 入驻免押金，提现前补交：注册时不要求押金；提现时按当前打手等级配置的提现押金校验，已缴纳部分会抵扣，不足部分可在打手端补交。

“打手等级分类”新增“提现押金”金额。等级调整后，下一次提现按新等级标准复核；0 表示该等级无需提现押金。押金支付记录仍保留在支付流水中，便于运营核对。

本次发布后端、管理后台和 H5 1.3.7。

公众号模板通知未在功能商城启用时，管理后台的公众号通知菜单与系统配置分组、用户/打手/客服端的公众号通知入口均会隐藏；功能商城中的付费模块仍保留，用于查看授权和开通。
