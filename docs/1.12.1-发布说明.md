# 沧烁 Delta 1.12.1 补丁发布说明

- 版本：`1.12.1`
- 版本类型：PATCH，修复 `1.12.0` 正式版验收发现的两个 HTTP 状态码问题
- 发布基线：`1.12.0` 正式版及其后的主线共享改造
- 数据库：`schemaVersion=1`，本补丁没有数据库结构变更

## 修复内容

- 不存在的静态资源不再被全局异常处理器包装成 HTTP 200 JSON，实际返回 HTTP 404，响应体 `code=404`。
- 共享租户模式下，WebSocket 握手继续校验 Host 与 Origin 属于同一启用租户；跨租户来源现在返回 HTTP 403，不再以 101 建立连接。
- WebSocket 握手限流拒绝现在返回 HTTP 429，便于客户端和网关区分频率限制。

## 版本对齐

- 后端 `catalog.json`：`1.12.1`，`channel=stable`，`schemaVersion=1`。
- 管理后台 `package.json` 和锁文件：`1.12.1`。
- H5/小程序 `package.json` 和锁文件：`1.12.1`。
- 小程序 `manifest.json`：`versionName=1.12.1`，`versionCode=184`。

## 验证

- 后端全量 315 项测试通过，`mvn -pl delta-admin -am verify` 成功。
- 真实嵌入式 Tomcat 握手验证：允许来源返回 101，跨租户来源返回 403。
- MVC 资源处理链验证：缺失静态资源返回 404。
- 管理后台 69 项、H5 86 项测试通过；管理后台、H5 和微信小程序生产构建成功。
- 更新器 28 项、迁移工具 21 项测试通过。

## 兼容与风险

- 本补丁不启用共享生产模式，不修改客户数据库、域名、支付回调或授权配置。
- `1.12.0` 引入的共享多租户能力仍默认关闭；生产客户继续使用原有单租户路径。
- WebSocket 拒绝状态的变化只影响被拒绝的握手，不改变允许来源的正常连接协议。
