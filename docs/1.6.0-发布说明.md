# 1.6.0 待办中心与消息提醒

- 管理后台仪表盘顶部新增「今日待办」。按全部、紧急、未读筛选，点击「去处理」进入对应业务记录。
- 待办、系统通知和客服聊天分别显示未读。已读只清除本人提醒，业务办结后自动移除待办；客服广播按账号记录已读。
- 移动端客服工作台、打手中心和会员「我的」加入待办入口。未登录浏览「我的」不触发待办登录跳转。
- 首页公告的正文与「我知道了」按钮留出间距，长公告更易阅读。

## 安装方式

请登录所属项目的管理后台，进入「功能与更新 → 系统更新」，点击「检查正式版」，查看并安装 1.6.0。此版本的后端、管理后台和 H5 需作为同一批必要更新安装。后端启动时自动新增两张已读回执表，不修改既有订单、支付和通知数据。微信小程序由项目方按既有流程另行提交。

详细用法与迁移说明见 [待办中心文档](workbench.md)。
