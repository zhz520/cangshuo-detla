# 沧烁 Delta 1.12.3 补丁发布说明

- 版本：`1.12.3`
- 版本类型：PATCH，共享租户授权校验修复
- 数据库：`schemaVersion=1`，无结构变更

## 修复内容

- 共享模式下，租户 license 校验现在使用该租户注册的 `platformCustomerId`，不再错误使用全局 `PLATFORM_CUSTOMER_ID`。
- 修复 742 等客户在共享服务组中 license 本地校验不通过、授权快照不上报、功能权益和版本状态异常的问题。
- 单租户默认路径保持兼容；租户数据库、文件、Redis 和发布协议不变。

## 版本对齐

- 后端 catalog、管理后台、H5 和小程序统一为 `1.12.3`。
- 小程序 `versionCode=186`。
- 数据库 `schemaVersion=1`。

## 验证要求

- 后端全量测试通过，新增共享租户 license 客户编号隔离测试。
- 管理后台、H5 构建通过，静态资源检查通过。
- 742 共享租户能够读取 license，授权快照按 1.12.3 上报，JAX 不受影响。
