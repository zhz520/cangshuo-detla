# Delta 1.18.3 发布说明

- 版本：1.18.3
- 基线：共享组 1.18.2
- 分支：`codex/product-content-and-purchase-mode`
- 数据库：`schemaVersion=1`，无新增表或字段

## 修复与配置

- 商品富文本描述中的图片现在在前台“详情与须知”正常渲染，不再只显示去掉标签后的文字摘要。
- 富文本图片继续经过标签、属性和 URL 白名单过滤，并统一限制最大宽度。
- 新增后台开关“暂停购买时仅联系客服”，位置在：支付与交易 → 下单与协作。
- 三种前台状态：购买开启时显示“立即购买”；购买关闭且联系客服开启时显示“联系客服购买”；两者都关闭时显示“购买已暂停”。
- 联系客服购买模式仍禁止创建订单，不会绕过服务端购买关闭校验。

## 验证

- 后端相关配置与数据库兼容测试通过。
- 管理端 102 项测试、H5 113 项测试通过，两端生产构建通过。
- 商品详情测试覆盖描述富文本、图片样式、联系客服购买和暂停状态。
