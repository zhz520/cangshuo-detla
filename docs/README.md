## 文档维护约定

- 长期有效的规则、方案、发布说明和验收记录放在 `docs/`；临时脚本和一次性审计放在已被忽略的 `.tmp/`，任务结束前清理。
- 新增长期文档时，在本索引补充一行；会误导当前发布或已被 Markdown 完全替代的旧格式材料，可保留外部归档后从工作树移除，并在索引和清理记录中说明。
- 正式发布说明按版本新增，不改写已发布版本的历史记录；需要更正时新增补丁说明。
- 含密码、Token、私钥、支付证书、完整手机号或客户业务数据的材料不得写入文档、截图或 Git。
