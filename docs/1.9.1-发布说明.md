# 1.9.1 通知模板完整示例

- 系统配置中的公众号通知和短信通知，每个角色模板组下方均可展开查看完整示例。
- 客户、打手、管理员、客服四份公众号模板组分别覆盖 `new_order`、`order_status`、`refund_status`、`complaint_status`、`staff_review` 五类事件。
- 客户、打手、管理员、客服四份短信模板组分别覆盖上述五类事件，并展示阿里云变量与系统数据源的对应关系。
- 每份示例均可一键复制，明确标出必须替换的微信模板 ID、阿里云短信模板 Code 和左侧变量名。
- 完整示例同时整理在客户仓库的 `docs/通知模板完整示例.md`。

## 安装方式

客户自行登录所属项目管理后台，进入「功能与更新 → 系统更新」，检查并安装 1.9.1。后端、管理后台和 H5 保持同一发布批次；本次业务代码主要为管理后台配置页增加示例和复制入口。

示例中的占位值不能直接用于发送。必须替换为当前公众号后台或阿里云短信后台已审核通过的真实模板，并按实际模板字段核对其中的变量名。
