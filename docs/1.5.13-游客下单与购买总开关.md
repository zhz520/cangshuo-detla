# 1.5.13 游客下单与购买总开关

本版本按方案 A 增加游客影子账户，不需要重构现有订单、支付、退款、聊天、售后和结算主流程。

## 新增能力

- H5 未登录用户可以使用手机号、6 至 12 位查单码和隐私同意凭证创建游客订单。
- 游客通过手机号和查单码重新查询订单，支付、投诉、取消和售后沿用原订单权限。
- 正式账号可以绑定已完结的游客订单；绑定只建立关联，不修改游客用户 ID、订单归属或资金流水。
- 后台“系统配置 > 订单配置”新增“启用前台购买”和“允许游客下单”两个独立开关。
- 关闭前台购买后，商品详情、打手详情和打手列表中的购买入口隐藏，服务端同时拒绝新订单。

## 安全边界

- 游客手机号和查单码仅保存 HMAC-SHA256 摘要，手机号以脱敏形式展示。
- 游客影子账户被用户列表、新用户统计、消费榜和公告群发排除；游客订单仍计入订单和成交统计。
- 游客不能使用余额支付、充值、小程序支付、打赏、评价或打手入驻。
- 待支付、待接单、履约中、待确认、退款中和争议中的游客订单不能绑定正式账号。
- 游客角色只能访问自己订单、聊天、文件和售后接口，其他普通接口统一拒绝。

## 升级说明

- 数据库结构版本仍为 1；启动兼容模块会以幂等方式新增 `user.is_guest`、`guest_checkout_profile`、`guest_user_link` 和两个订单配置。
- 独立迁移文件位于 `deploy/baota/migrations/20261106-guest-checkout.sql`，可重复执行。
- H5 和后台构建版本、后端平台目录版本统一为 `1.5.13`。
- 授权中心正式版需要同步 `cangshuo-backend.zip`、`cangshuo-admin.zip` 和 `cangshuo-h5.zip`，且 GitHub Release 资产必须包含 SHA-256 digest。
