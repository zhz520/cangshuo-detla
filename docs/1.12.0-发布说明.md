# 沧烁 Delta 1.12.0 发布候选说明

- 版本：`1.12.0`（候选，尚未创建正式标签或 GitHub Release）
- 版本类型：MINOR，新增共享多租户运行时和迁移工具
- 当前状态：主线仍是 `1.11.2`；本文件来自候选分支，生产客户未升级

## 主要变更

- 共享多租户运行时：域名注册与 Host 路由、租户上下文、租户绑定 JWT、Redis 命名空间、按租户路由数据库、连接池预算和逐租户启动兼容检查。
- 业务隔离：微信支付客户端、公众号 access token、小程序客户端、WebSocket、CORS、上传文件、私密文件、定时任务、维护开关和授权状态按租户隔离。
- 发布与迁移：共享服务组发布计划验签、dry-run、逐租户备份、制品摘要校验、Compose 覆盖安装、三组件健康检查、失败回退、中断恢复和审计。
- 迁移工具：文件增量清单/复制/校验、财务对账、租户迁移状态机、742 变更单草案。
- 维护期支付回调：全局维护模式下支付、退款和公众号回调仍可到达验签入口，状态和健康检查不被 503 拦截。
- 兼容保留：单启用租户时历史无租户前缀 `/file/` 和缩略图 URL 继续可用；多租户启用后旧路径拒绝。

## 未完成门禁

- 共享模式默认仍为 `tenant.enabled=false`，不能在当前生产直接启用。
- 没有正式 GitHub 标签、Release、授权中心版本目录或客户更新项。
- 742 生产仍是单租户 `1.11.2`，未执行真实数据导入、文件正式同步、维护窗口切换或微信账单逐笔核对。
- 真实微信支付/退款回调、WebSocket 真机和客户验收仍需在正式迁移窗口完成。

本候选包只用于内部验收和迁移演练；发布前必须完成版本评审、正式标签、Release 资产摘要和授权中心登记。
