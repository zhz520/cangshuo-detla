# 公众号通知四角色配置

公众号通知支持客户、打手、管理员、客服四种独立模板。不同角色可以使用不同微信公众号模板，也可以复用同一个微信模板 ID，但字段映射必须与角色实际收到的内容一致。

## 后台位置

「系统管理 → 系统配置 → 公众号通知」：

| 配置项 | 角色 |
|---|---|
| 客户专属模板组 | 普通用户、游客客户 |
| 打手专属模板组 | 接单员 |
| 管理员专属模板组 | 管理员 |
| 客服专属模板组 | 客服 |

每份模板组都是一个 JSON 对象，包含以下事件中的所有或部分分组：

- `new_order`：订单支付、新订单
- `order_accepted`：订单已接单
- `order_completed`：订单已完成
- `material_reviewed`：素材审核、打手冻结
- `withdraw_reviewed`：提现审核结果

每组格式：

```json
{
  "new_order": {
    "templateId": "微信模板ID",
    "fields": {
      "thing1": "message",
      "character_string2": "orderNo",
      "phrase3": "status",
      "time4": "time"
    }
  }
}
```

字段值只能使用：`message`、`status`、`time`、`orderNo`、`amount`。

## 角色建议

- 客户模板突出“订单状态、订单号、处理时间”。
- 打手模板突出“指派/接单、审核结果、提现结果”。
- 管理员模板突出“新订单、异常处理、待确认事项”。
- 客服模板突出“新订单待接待、接单后跟进、完成待确认”。

素材审核和提现审核通常没有订单号，不建议映射 `orderNo` 和 `amount`。

## 绑定

- 客户：用户端「我的 → 公众号消息通知」。
- 打手：接单员中心「我的 → 公众号消息通知」。
- 管理员、客服：微信内打开 `https://jgs.kk520yy.com/#/pages-cs/login/index`，使用后台账号登录，再进入「我的 → 公众号消息通知」。

绑定必须在微信内置浏览器完成，并且所有接收人应先关注配置的公众号。
