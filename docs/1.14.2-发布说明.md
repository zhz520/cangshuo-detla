# Delta 1.14.2 发布说明

- 发布日期：2026-11-12
- 适用组件：后端、管理后台、H5；本批无小程序功能变更
- 数据库：schemaVersion=1，无结构变更

## 客户 H5 首页优化

- 将“消费排行、会员、优惠券、邀请”四张纵向大卡片收敛为一行四个紧凑图标入口，减少首屏占用。
- 商品推荐提前到首页首屏可见位置，不再被运营入口挤压。
- 没有轮播图或分类数据时不再渲染空白大块。
- 最近购买改为底部悬浮滚动条，按后台开关和用户授权数据显示；没有数据时完全隐藏，用户可关闭。
- 点击“更多”直接打开最近购买标签；消费排行入口直接打开排行标签。

## 隐私与开关

- 最近购买仍要求用户主动打开展示授权，后台 `display.purchase_feed.enabled` 未开启时不显示。
- 不展示订单号、金额、联系方式或未授权用户的购买记录。

## 验证

- H5 Node 测试 93 项通过，H5 生产构建通过。
- 后台 Node 测试 74 项和生产构建通过；后端全量 380 项测试通过。
- 添加首页信息层级、空轮播/空分类、悬浮滚动条和标签定位回归测试。
