# 1.3.3 客户端版本检查修复

某些版本只更新后端或管理后台，例如 1.3.2 只包含管理后台。此前系统把后端、管理后台、H5 的最低组件版本当作整体版本，导致 742 安装后仍显示 1.2.0 并继续提示 1.3.2 可更新。

现在优先使用最近一次成功安装的签名计划目标版本，并由更新执行器写入整体发布版本；旧实例没有成功计划时仍按最低组件版本安全判断。组件版本继续单独维护，后续只更新某个前端或后端时不会漏掉未安装组件。

本次同时发布后端与管理后台组件 1.3.3；管理后台界面代码与 1.3.2 相同，更新组件版本以组成完整、可校验的 1.3.3 发布包。H5 1.2.0 保持不变。
