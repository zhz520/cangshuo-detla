# 1.8.1 管理员账号冲突修复

- 修复新增管理员时输入曾删除账号的用户名会触发数据库唯一键异常并返回 500 的问题。
- 旧账号记录会先归档重命名，再创建新的独立管理员账号；不会恢复旧账号 ID、密码或登录会话。
- 编辑管理员时同样支持安全复用已删除账号的用户名。
- 所有数据库唯一键冲突统一返回 409，并显示明确的业务提示，不再出现“服务暂时不可用，请稍后重试”。
- 后端、管理后台和 H5 作为同一批必要更新发布，组件版本统一为 1.8.1。

## 安装方式

客户自行登录所属项目管理后台，进入「功能与更新 → 系统更新」，检查并安装 1.8.1。系统启动不需要手工执行数据库升级脚本。
