# 1.3.9 第三方客服导航与首页图标

- 用户端选择第三方企业微信客服且填写有效 HTTPS 链接后，底部导航隐藏“消息”页签，其余页签会按可用数量重新排列并保持当前页高亮。
- 企业微信客服链接为空或无效时仍回退系统内置客服，“消息”页签继续显示，避免误删站内会话入口。
- “系统配置 > 客服配置”新增“首页客服悬浮图标”开关，默认开启；关闭后只隐藏首页悬浮客服，不影响商品详情和“我的”页面客服入口。
- 接单员端和客服端导航不受第三方客服模式影响，订单会话仍可正常使用。
- 后端启动前增加数据库结构兼容检查：升级包先确认 `player_level.withdraw_deposit_amount` 字段存在，缺失时按安全默认值自动补齐，避免代码已升级但数据库未升级造成的页面 503。

本次发布后端、管理后台和 H5 1.3.9。
