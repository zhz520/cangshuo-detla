# 1.4.3 客户功能授权与续费

授权运营中心新增实例级“客户功能”管理，每个付费功能独立记录开通状态、生效时间、到期时间、价格周期和剩余天数，可新增、编辑、启停、删除与续费。

购买订单创建时会实时显示价格、周期、生效时间、到期时间、本次新增天数和剩余总天数。订单与授权均不能超过项目维护期。

客户端会严格校验并一次性保存项目声明中的 `licenseId`、`featureEnabled`、`featureStartsAt` 和 `featureExpiresAt`，项目与许可证引用不一致、项目签发时间不递增或功能期限缺少启用状态时拒绝整次更新。后两张映射保留已购买但停用的功能期限和未来未知功能编号；从未收到托管字段的旧项目继续使用本地开关，已经识别远端托管后收到缺字段的旧响应则拒绝回退。项目状态和授权状态保存在同一原子状态文件中，重启后维护暂停和域名校验仍使用最近一次已验签快照，`authority.json` 只作为展示缓存。付费功能卡片会显示参考周期、受维护期限制的实际可购天数、生效时间、到期时间和剩余天数，已购买功能提供人工续费入口。许可证格式和 claims 字段保持兼容，旧许可证仍使用原有时间字段。

本次改动涉及后端、管理后台和版本对齐，H5 业务逻辑不变。
