# 1.9.8 工作人员后台域名与移动入口重构

- 管理员、客服不再使用客户 H5 中隐藏的 `pages-cs` 工作台。客户 H5 只保留旧地址兼容跳转，不再保存工作人员登录凭据。
- 管理后台新增正式 `/mobile` 路由目录。手机访问后台会自动进入 `/mobile/login`，登录后进入 `/mobile/dashboard`；订单、人员、退款、投诉、审核、聊天等业务深链保持在 `/mobile/...` 下。
- 桌面端继续使用原有后台地址和布局。后台已有的手机工作台、权限过滤、卡片表格和聊天适配直接复用，不再维护两套工作人员移动端。
- 管理员、客服公众号绑定迁移到后台 `/wechat-binding`，手机地址为 `/mobile/wechat-binding`；绑定身份根据当前后台账号自动识别，不再使用客户 H5 的 `role=cs` 参数。
- 系统配置新增 `site.staff_web_url`（工作人员后台地址）。客户 H5 旧工作人员地址会跳转到该 HTTPS Origin；未配置时只显示联系管理员提示。
- 公众号绑定回调配置需要改为后台绑定页，例如 `https://jgsapi.example.com/mobile/wechat-binding`。微信公众平台网页授权域名也必须是工作人员后台域名。
- 客户 H5 “我的”页面移除连续长按资料卡进入后台的隐藏入口；旧 `/pages-cs/login/index` 和旧待办链接提供兼容转交。
- 完成旧地址跳转、手机自动分流、移动深链、权限校验、公众号回调、客户 H5 构建和后台安全整改测试。

## 安装与配置

客户在「功能与更新 → 系统更新」安装 `1.9.8`。后端、管理后台和 H5 需要同批更新。

安装后由管理员完成两项配置：

1. 「系统配置 → 站点配置 → 工作人员后台地址」填写后台 HTTPS Origin，例如 `https://jgsapi.kk520yy.com`。
2. 「系统配置 → 公众号通知 → 公众号绑定回调页面」填写 `https://jgsapi.kk520yy.com/mobile/wechat-binding`，并在微信公众平台配置同一域名为网页授权域名。

完成配置后，管理员和客服在手机微信打开后台域名即可自动进入移动工作台；绑定后按各自角色接收通知。
