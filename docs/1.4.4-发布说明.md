# 1.4.4 微信公众号支付与更新稳定性修复

- 微信支付新增公众号支付（JSAPI）：微信内置浏览器通过 `snsapi_base` 网页授权取得公众号 OpenID，调用微信支付 JSAPI 并调起收银台。
- 订单支付、余额充值、打手入驻押金和提现前补押金均覆盖公众号支付。
- 小程序支付、公众号支付、微信外 H5 支付拆分为独立开关；公众号支付使用独立 AppID 和 AppSecret，避免与小程序的 OpenID 混用。
- 微信支付单按场景和 AppID 隔离并持久化，切换支付方式时不会复用旧场景的商户订单号；小程序支付和 H5 支付开关由服务端强制校验。
- 切换支付场景时自动关闭其他未完成的打手押金单；若回调发现押金已足额或本笔会超额，将自动原路退款，避免重复扣款。
- 修复 1.4.2/1.4.3 正式后端启动失败问题：邮件通知服务存在多个构造器，Spring 无法自动选择，现显式注入生产构造器并增加启动级回归测试。
- 新增公众号支付配置与微信支付商户平台配置教程。
- 客服和管理员登录后台后可在右上角账号菜单修改本人密码；修改后旧登录令牌立即失效，需要使用新密码重新登录。
- 数据库 schemaVersion 保持为 1；许可证 claims 字段保持兼容。
