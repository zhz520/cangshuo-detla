# 1.4.2 邮件通知付费模块

功能商城新增“邮件通知”模块，标准价格 **¥50.00**，最低客户端版本 1.4.2，按实例购买，期限跟随项目维护期。未购买或未启用时，后台邮件配置入口和接口均不可用。

启用后，在“系统设置 → 邮件通知”配置客户自有 SMTP：服务器、端口、TLS/STARTTLS、邮箱账号、授权码、发件邮箱和发件人名称。运营收件人支持最多 20 个地址，可用逗号、分号或换行批量添加，系统按大小写不敏感方式去重。

可独立开关的重要事件：订单支付、指派、接单、完成、取消和退款；新投诉及投诉处理；提现申请、完成和驳回；打手审核通过、驳回和冻结；资料审核、新评价及收益结算。未勾选事件不会进入队列。

同一业务事件与同一收件人由事件哈希和收件人唯一约束去重。邮件使用品牌化 HTML 正文并提供纯文本备用；发送失败最多重试 5 次，待发记录超过一天自动过期，管理后台保留状态、错误代码和人工重试入口。SMTP 密码不回显，也不能通过通用系统配置接口读取或修改。
